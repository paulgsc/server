# idea_repo

The owner's ideas, kept on home as one record each (STUDIO ST26): every revision
the phone sends of an idea (`idea_revision`) with its answers (`idea_answer`),
the "still furnishing" mark (`idea_furnishing`), the set-aside mark
(`idea_set_aside`), and the marks that edit the topics and keywords lists
(`idea_list_mark`), append-only and per subject. The rules are in `src/lib.rs`
and `src/model.rs`, and in `docs/identity.md`, invariant 32.
